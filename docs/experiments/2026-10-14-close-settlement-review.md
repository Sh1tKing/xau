# 黄金平仓利润与通知结算修复

日期：2026-10-14。版本：`close-settlement-v1`。本次代码签名：`4cc1c2c83cc0a4c7`。

## 用户实例与原问题

截图中ticket=607686331，SELL 0.01，4154.56→4142.60，MT5利润11.96；飞书16:56:21只显示“本次盈亏: 未知（未查到历史成交）”和“最后浮动盈亏: +$11.94”。11.94是平仓前最后一次持仓快照，11.96是截图里的实际成交利润，两者不能互换。同步主日志截至18:55:45，16:16:08确认真实fill_price=4154.56，16:56:22有通知发送记录，但没有这笔完整历史成交回执。

代码检查确认四处缺陷：

1. 原始position.time使用服务器时钟，旧查询把它转本机datetime，并以本机datetime.now截止。服务器时钟领先时，短持仓的查询起点可能已经晚于终点。原代码没有按持仓ID直接查询。
2. 未匹配到本票时允许选同品种、一小时内的其它平仓成交，可能把邻单结果归给这笔单。
3. 只取最后一笔OUT，将该笔profit+commission+swap+fee称为整笔净盈亏，漏开仓费用及较早的分批成交。
4. 历史未到时立即发未知和最后浮盈，并标记已通知、清除快照及评分，不再核对；持仓读取None也被当成空仓，可能误报平仓。

截图不能证明真实DEAL_REASON或完整费用分项。本次离线实例以截图的价格/利润和零费用建模，没有请求真实MT5历史或补发旧消息。

## 新结算规则

[MT5历史接口](https://www.mql5.com/en/docs/python_metatrader5/mt5historydealsget_py)支持按position对应DEAL_POSITION_ID返回关联成交；[持仓属性](https://www.mql5.com/en/docs/constants/tradingconstants/positionproperties)说明POSITION_IDENTIFIER贯穿生命周期，而ticket可能改变。因此使用`history_deals_get(position=snapshot.identifier)`，identifier缺失才使用本票ticket；不再发本机日期范围，也不猜邻单。

`strategies/settlement.py`为不连接终端的纯函数，严格匹配position_id、symbol及原方向：

- 汇总所有IN、OUT、OUT_BY的真实profit、commission、swap、fee，净盈亏为四项之和；不从价格差、余额变化、最后浮盈或原止损推算。
- 完整开仓和平仓数量必须相等，已返回总量不能小于最后已知持仓量；缺开仓、缺平仓、部分未平或无效金额继续待核对。
- 相同deal ticket只计一次，冲突重复拒绝；分批开/平价格按实际成交量加权，通知手数为完整持仓成交量。
- 净持仓反转INOUT不能无依据归给单一原入场快照，本版拒绝自动出结算数并保留待核日志；不制造一个利润值。账户级入出金等不计为本票收益。

利润、佣金、库存费和fee字段的来源见[成交属性](https://www.mql5.com/en/docs/constants/tradingconstants/dealproperties)。费用按经纪商返回的正负号相加，不重复减点差、原position.swap或锁盈估算费用。

## 延迟回执和通知

主动平仓成功后仍立即登记原策略冷却、保留原交易行为，改为登记待结算通知；取消原三次sleep查询。止盈/止损或外部平仓由常规持仓同步发现。持仓查询返回None不声称已平仓，也不删除AI原持仓上下文；相同identifier仍有持仓时不发全部平仓通知。

待核记录保存最后持仓快照、已知开仓评分及程序平仓原因，普通轮询以2–30秒退避核历史，不增加AI请求。不完整历史继续保留，完整历史与飞书成功后才标记已通知；飞书关闭/未配置时只做日志结算。MT5锁保护终端取数，飞书HTTP不持有该锁。

`close_notification_state.json`在guardian状态同目录，默认`xau_fib_pa_logs`。它原子落盘，绑定账户login、server、symbol、magic；重启后只恢复同账户待核记录，重启即重新核对。文件写入失败会明确记日志并保持内存队列，不阻止已授权的保护性平仓。极端进程中断/通知回执丢失仍不能保证网络侧绝对只发送一次；本地成功后不重复发送。

最终飞书结果明确使用“本次净盈亏”，删除历史未知和最后浮盈；缺失开仓评分、余额/净值行省略。最新SL/TP准确标为“平仓前止损/止盈”，不再误称为原始止损。已知程序平仓原因保留，外部原因来自真实成交reason。

示例在零费用假设下显示：

```text
本次净盈亏: +$11.96
开仓价 → 平仓价: 4154.56 → 4142.60
成交盈亏/总费用: +$11.96 / +$0.00
```
