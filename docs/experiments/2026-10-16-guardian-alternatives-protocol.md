# 六种提前减险方案：事前固定实验

用户要求寻找别的方法并做多个测试。本轮只做离线研究，正式策略、AI提示词、实际.env、部署和状态不改。本协议在六个候选的结果生成前写入；不根据结果逐次找阈值，不组合“最优参数”。

## 共用事实和执行

使用同一份1958笔旧本地固定入场、同一M1/M5缓存；方向/入场价/原SLTP/0.01手/SL8/0.10费用/当前v3阶梯保持。原控制90分钟共同观察期限不代表当前自主仓到时退出。BUY/SELL镜像，所有新信号必须当时扣费浮盈不为正，不加仓、不反手。闭合M1的新信号最早下一分钟开盘生效，分别加0/1/2根M1等待压力。等待0是乐观边界，不能模拟真实两秒或盘口路径。

SL提案继续使用原完整、只升不降的M5 ATR空间、三倍点差、0.50和代理broker间隔的最大值，并在末两根M1极值外留0.15M5 ATR；不借现金阶梯的窄空间例外。执行重验当前报价/空间/当前更强SL，变化须达到原推进步长。收紧后不能回退。

主动退出是单独的激进研究对照，不伪装成“始终保留M5 SL空间”。执行时若原SL/TP已在开盘触发，先承认原保护；报价已恢复到净盈利则取消旧退出提案。额外等待期间原SLTP和阶梯一直有效。每个实际执行的新主动退出，再分别计0.10额外不利成交成本的压力（SL/TP和共同费用保持）；不是调整模型选赢家。

### 固定构件

- **M1连续走弱**：三个连续、入场后的闭合M1，末两根均逆向实体，收盘连续不利推进，末根高低点也同向不利移动；末两根均无本方向长影线拒绝。拒绝沿用1.6倍实体、0.18M1 ATR14和55%收盘位置。
- **M5温和走弱**：新闭合M5发生在入场后，且与前根连续，逆向实体、收盘比前根更差、BUY高点更低/SELL低点更高；不要求穿过前根极值。该M5没有本方向拒绝影线，距离确认不超过5分钟。
- **峰值**只取入场后已闭合M1的可平仓侧净浮盈，不使用尚未完成K线的high/low，也不宣称是真实最高tick浮盈。R为原止损距离，不随SL收紧重算。

## 六个候选（各一套参数）

| id | 做法 | 固定触发 |
|---|---|---|
| fast_m1_sl | 不等M5破位，提前收紧SL | M1连续走弱；仍保留完整M5空间 |
| soft_m5_sl | M5温和走弱时收紧SL | M5温和走弱，末两根M1连续且在入场后，最新M1无本方向拒绝；不要求M1连续两根逆向 |
| failed_start_sl | 开仓缺乏推进后减险 | 至少5分钟，闭合净峰值<0.25R，末两根M1均收出最初三根M1区间的不利边界，且M1连续走弱；只收紧SL，时间本身不退出 |
| volatility_exit | 波动尺度的风险退出 | 从入场价的不利位移≥1.5倍入场时已闭合M5 ATR，同时M1连续走弱和M5温和走弱；主动退出 |
| fast_m1_exit | 更激进的提前退出对照 | 与fast_m1_sl相同的M1连续走弱，但直接退出 |
| giveback_exit | 小幅有利推进后失去优势 | 闭合净峰值≥0.25R，随后回到净浮盈不为正，且M1连续走弱；主动退出 |

这些参数是研究假设，不是已有AI规则或已验证黄金优势。波动法的出发点是ATR反映波动而非方向；具体1.5倍也不能直接证明本项目的收益。[Fidelity ATR说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)。SL保留合理空间的原则参考[CME止损说明](https://www.cmegroup.com/education/courses/trade-and-risk-management/proper-position-size)，不改用户已有仓位与风险限制。
