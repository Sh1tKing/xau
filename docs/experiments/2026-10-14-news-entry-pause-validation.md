# 重大美国事件入场休息验证

用户指定每个发布时间前后各15分钟。`news-pause-v1`在Python暂停新入场和AI-1/AI-2开仓请求，已有仓位的原SLTP、实时单向锁盈、AI-3及成交结算继续。并未更改方向、评分、止损/盈亏比上限或仓量。

## 日程与时间

| 事件 | 数据源 |
| --- | --- |
| 非农、CPI、PPI | [BLS官方订阅](https://www.bls.gov/schedule/news_release/bls.ics)、[2026官方年历](https://www.bls.gov/schedule/2026/)；取数失败可用[Forex Factory周历](https://www.forexfactory.com/calendar)对应的BLS事件 |
| 全国GDP、PCE | [BEA全国发布日程JSON](https://apps.bea.gov/API/signup/release_dates.json)；精确匹配全国统计，排除州/县同名数据 |
| FOMC决议、发布会、纪要 | [美联储2026年10月日历](https://www.federalreserve.gov/newsevents/2026-october.htm)、11/12月同格式；使用发布行的日期和时刻，不能拿两日会议首日当发布日 |

发布时间带时区，统一到UTC。官方美国当地时间通过America/New_York处理DST，与MT5服务器UTC偏移无关。窗口起点包含、终点不包含；相接/重叠合并。例如2026-10-14 CPI北京时间20:30，休息20:15–20:45；10月28日FOMC决议及发布会对应北京时间10月29日02:00/02:30，合并休息01:45–02:45。12月同样的美国14:00是次日北京03:00。

日历只覆盖表内事件，不声称覆盖所有央行官员讲话、临时新闻、数据泄漏或无精确时间的事件。日历事件关联不证明两笔历史止损的实际成因，本改动也不证明收益提升。

## 可靠性与部署

后台每6小时刷新；失败15分钟后再试。行情/护盘不等待网络，日历缓存原子替换且写盘/fsync不持有供下单检查使用的日历锁。每个必需来源必须有有效覆盖；核对数据最多7天，错误/缺失/过期不能被当成“没有事件”。日志区分新闻休息、日历不可用、普通AI观望与API失败。新仓暂停不消费尚未POST的分析scope；已发送请求仍记录真实usage，不假定取消上游费用。

随源码提供`strategies/calendars/us_major_events.json`，2026-10-14核对BLS官方年历，并实际获取BEA及美联储10/11/12月页面生成；作为有期限启动备用，不自动延长其verified_at。开发机实际访问BLS ICS/HTML返回403，Forex Factory周历读取超时，BEA JSON及Fed页面返回200。不能声称服务器全部日历来源已联通；缓存超过有效期且来源仍不可用时只暂停新单，护盘继续。需要从真正核对的新日程恢复，不可伪造核对时间。

每个AI-1/AI-2实际POST前检查，慢回复、主备重试、最终订单都不能跨入窗口。窗口结束后旧任务也不能排队提交，必须重读行情。下单预留前及最终order_send前都检查；若边界恰好在持久预留之后，禁止发单但保留现有预留不回滚政策。

复制两个主脚本和完整strategies目录，包括calendars子目录，保留服务器实际.env、日历缓存及现仓状态，由用户重启。不启动交易进程，不发送真实AI/飞书请求，不推送远程。crypto_demo、local_guard_demo和历史纯本地回放保持原系统。

最终源码和部署副本各681项全套通过，分别另过两项内置自检、策略CLI及六文件语法检查；两侧运行签名同为`f7ac6d72b6680b3c`。其中32项为本次专项。受控地移除入场新闻门后，窗口内零HTTP/零scope/零事件预留测试按预期失败，确认它能检测缺失的拦截行为。只读日历CLI默认启用且通过当前日程检查。
