# BTC / ETH 副本离线验收

本轮实现独立 `crypto_demo/`，复制来源为黄金运行代码 `7f3df37`，公开分支父提交为干净快照 `00376b31e5b1c0d6b6ac02a408174a276df30898`。实现提交 `ce98f99192daa0392ac018c8dfc49fdd60e2022a`，复审修补提交 `241dd2f789546d4c11b9175ccc1f7a0b4a0c1f82`。发布文本以分支最新代码及 `crypto_demo/MANIFEST.json` 为准。

初次控制器独立测试为102项通过，但任务复审另外复现三项漏测：observe启动在只读配置检查时报错，账户切换或未知持仓查询可能清除原上下文，非法报价可能污染护盘极值。本轮均在加密副本修复，黄金原脚本未改。这说明初次测试不能替代边界复审。

修补增加15项回归方法，覆盖完整 `run(once=True)` 观察启动及退出、实际POST前模式门、账户切换/native None前后的内存和磁盘状态、无效报价/ATR后的BUY及SELL恢复。冻结期限不依赖普通护盘开关或ATR；无效报价/合约阻止期限操作，正常报价后继续执行。修补前新增回归32项失败17项/报错3项，修后32项通过；最终覆盖组80项通过。只使用占位凭据、模拟合约/行情/AI/订单接口；未连接或启动 MT5，未请求付费 AI，未启动交易。

覆盖 BTC/ETH 买卖四条真实宿主链路：本地自主分析上下文、Messages 响应、质量证据、AI-1 定稿、AI-2 新报价审核、合约现金手数及保证金、订单检查、预提交 token 和模拟发送；另测 AI-3 原冻结期限在定义重载后保持。报价漂移只会拒绝固定 SL/TP，不能移动它们凑条件。包括未知/实盘/已有仓/切换账户、观察及 dry-run 禁止全部订单修改、最小手数、非 .01 tick、现金和费用后的 RR、保证金缩量、跨进程锁与崩溃释放、跨币种/复制目录的不确定回执状态。

BTC/ETH `--check` 分别只发现 `btc_adaptive` / `eth_adaptive`，默认模式 `observe`。CSV 研究入口 `--help` 明确旧黄金现金回放不可用，现货数据不生成 CFD/AI 利润。清单独立验证 **42 个 SHA256**，按 Git 文本 CRLF→LF 后计算，与发布文本一致。

黄金保全核对：22 个原运行/策略文件和 453 个原私有配置、日志、状态、部署及缓存文件 SHA256 与开工基线一致。没有把原 `.env` 或服务器配置复制进副本。公开分支仅从干净公开父系追加代码、示例和文档；不会上传本地旧 master 历史、日志、状态、实际凭据和研究缓存。

公开行情研究脚本另有 **4 项通过**，只检验闭合连续桶、异常输入及价格量级，不构成交易回测。采样来源、窗口、成本假设和延期失效计数见 [研究记录](2026-10-11-crypto-strategy-research.md)。

工程通过只说明离线代码通路和限制符合测试，实际经纪商合约能否容纳 100 美元账户、AI 决策频率、时延、费用、滑点和收益仍须由后续模拟日志验证。未知回执没有精确持仓可匹配时保持阻断；已成交后立即平仓的历史交易本版不自动核销，须人工核对历史和原 token 后处理状态。用户自行配置独立模拟账户并启动。
