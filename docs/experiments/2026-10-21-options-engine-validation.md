# 期权分析程序构建验证

日期：2026-10-21，北京时间。用户授权完整构建分析、通知、手动交易的期权程序。基础研究见同目录`2026-10-21-binance-options-video-analysis.md`，设计见`../superpowers/specs/2026-10-21-options-analysis-engine.md`。

## 代码范围

- `options_analysis/market.py`：固定白名单公开GET，币安期权元数据/指数/IV/双边深度、期货指数K线、商品日程。不包含账户/订单路径，不需要币安私钥。XAU未知则暂停，不替换其他标的。
- `indicators.py`：闭合且预热连续K线，MACD/MA5/MA60/ATR及确认支点；指数成交量明确不可用。
- `ai.py`：主分析/反方/人工持仓三个角色，明确Messages/Chat协议、同POST scope和引用、完整JSON验证、一次配置备用、可见回复及usage；不存私有思考。
- `pricing.py`：买入成本、乘数/数量网格/预算/双边深度、五种时间/标的/IV情景、费用假设。没有概率、收益保证或自动卖方裸卖。
- `engine.py`：原方案固定审核、两次最新行情复核、发送前时效和最高权利金约束、人工持仓复核与到期结算提醒、通知去重。
- `store.py`：SQLite原子预算/扫描/通知预留、真实人工成交、净费用盈亏，Windows/POSIX单实例锁。预留超时不返还预算，未知通知不补发。
- `config.py/setup_config.py`：专用配置；显式一次性复制模型参数，不在运行时加载黄金/crypto私有配置，不复制交易权限或飞书凭据。
- `news.py`：复用既有纯公开日历代码，显式独立缓存及公共种子，不改黄金代码、日历缓存或状态。
- `__main__.py/demo.py`：状态/诊断/单轮/持续扫描/合成演示/人工录入CLI。没有后台服务或自动启动任务。

默认15分钟检查；4h/6h主要判定、12h/日线背景、30m/1h/2h辅助，不是固定指标买卖。新候选严格校验成本/期限和独立反证；未设资金预算只算交易所最小数量成本，不能把它称为已决定仓位。配置、源码和文档没有交易所账户查询或下单能力。

## 实际模型请求

本轮共9次实际POST，全部计入本机独立预算账本；5次成功、4次诊断失败。连接小请求不等于全部生产分析已验证。

| 路线 | 实测结果 |
| --- | --- |
| `deepseek-v4-pro` | 复核角色小请求HTTP200、完整JSON、正确scope |
| `deepseek-flash` | 人工持仓角色小请求HTTP200、完整JSON、正确scope |
| `gpt-6.1-sol` | 小请求成功；随后两次完整合成行情输入也返回合法WATCH，scope及全部引用校验通过 |
| `claude-sonnet-5-5` | 初始测试禁用思考参数被400拒绝；改为尊重接口默认后上游502，不能称已恢复 |

一次旧备用诊断返回401，未用于最终主路。现本机期权主路是已验证的`gpt-6.1-sol`，原Claude连接保留为备用；复核及持仓为上述DeepSeek。一次性复制了已存在的连接参数，源私有配置逐字节保持，未推送凭据；中转的底层模型身份不能由本程序独立证明。

两次完整合成事实验证是实际调用模型，区别于`demo`的固定假回复；均明确标记合成，不接实时行情，不发送通知。供应商usage分别报告input/output为39500/1059和27393/1030；这只表示这两次请求，不是统一token、费用、遵约率或收益基准。后一请求使用最终无损紧凑编码。可见回复和公共输入保存在被忽略的本机SQLite，未提交。
