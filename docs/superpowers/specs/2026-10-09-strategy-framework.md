# 策略框架 v1

用户希望只修改策略内容即可自动识别，保留本地粗筛、AI-1自主提案、AI-2审核、AI-3护盘。因此采用可信本地Python定义接口，先迁移原三个策略，实验候选继续离线。未修改真实配置、模型、思考档位、门槛或交易进程。

`strategies/framework.py` 按源文件内容指纹发现、验证和缓存原子快照。每份定义集中提供评分、实际参数、JSON证据和三角色规则；语法及契约错误停止新开仓，不悄悄沿用上一次可用定义。`strategies/evidence.py` 仅格式化K线，不定义交易条件。

本地决策冻结一次策略快照，按session遍历策略，两方向分别评分并保持原优先级。选中策略的双向事实、契约和指纹随决策传递，AI输入不重新加载另一个版本。框架保留公共H1许可、保护止损、RR、追价、持仓及执行限制；策略blockers同时作用于本地与AI方案。目标倍数在声明边界内可调，默认1.8，公共RR1.5及止损8不变。

AI-1/2按同版本策略规则分析并核对原始市场数据。它们仍使用原质量/JSON/请求刷新契约和总请求预算；不会因为观望换模型找通过意见。审核中策略改变时停止旧提案，在实际order_send前再核对一次；已发送订单无法由文件更新撤销。已有仓位的策略契约、指纹和证据加入持久入场上下文，AI-3沿用原版本，定义文件错误不阻断持仓保护。

本地回测冻结开始时的定义。仍在每根已收盘M5评估、M1模拟原成交/护盘，没有重写模拟成交假设。初始迁移使用原版本8d9dc3逐项对照历史快照和14天全部交易/计数/拒绝理由；收益数字只用于迁移一致性，不能推广到AI交易或未来。

边界：自动发现支持现有数据接口内的策略，并不自动推断代码含义或引入任意新周期；修改算法时仍须同步同文件中的证据和规则。声明验证与离线检查不能证明交易优势。框架修改需重启，策略定义保存后在下一次本来应发生的评估/刷新时检查。停用全部时段策略会停止新开仓。

实现：三个主脚本、strategies包、使用说明及禁用模板。回归 `tests/test_strategy_framework.py` 覆盖新增/删除/停用/内容重载、失败关闭、参数证据一致、独立目标、旧提案拒绝、旧仓契约、回测冻结及输入去重。部署必须携带完整strategies包；公开发布允许范围新增strategies，仍禁止直接推送含密钥的旧master历史。

验收：框架21项生命周期回归、原139项回归及两个内置自检通过。160个缓存历史行情快照的方向、评分、保护价格和原拒绝理由逐项相同；14天阈值55/止损8的本地回放，迁移前后267笔的全部逐笔结果、流程计数及拒绝统计完全相同。真实`.env`、部署`.env`及缓存行情SHA256保持。未启动或重启交易，没有付费AI或MT5请求；不据此宣称AI动作分布、供应商服务或收益得到验证。
