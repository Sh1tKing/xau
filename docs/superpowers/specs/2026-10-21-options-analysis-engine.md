# 期权分析引擎 v1

用户授权完整构建；用途为 BTC、ETH、XAU 币安买方期权研究和飞书提醒，用户自行成交。没有交易密钥、账户查询或下单功能。黄金、crypto、local 样本和部署副本保持独立。

## 分析流程

默认每15分钟扫描，30m/1h/2h提供时机，4h/6h为主要判定周期，12h/1d提供背景。均取闭合K线；MACD(12,26,9)、MA5/60、ATR14、确认支点和背离只提供可核对事实，不把视频观点变成固定买卖信号。指数K线无真实成交量，不能将占位零当缩量。

公开GET获取币安 option exchangeInfo/index/mark/depth 及 futures indexPriceKlines；只接受实际列出的 USDT 合约，合约单位、数量步长、到期UTC和状态来自交易所。XAU同时检查商品交易日程；不以 PAXG 或 MT5 替换缺失的XAU数据。持仓合约不受新候选期限/价位筛选排除。

AI1独立输出方向、主周期、依据/反证、目标、失效、触发区间和兑现小时数；WAIT也是有效分析。主张引用本次请求事实短ID，快照摘要必须一致。Python按主张比较真实买卖价、期限、价差、IV和保守费用假设，生成目标快兑现/慢兑现/横盘/反向/IV回落情景。AI2独立复核固定方案，允许拒绝，不自行换合约或方向。AI3只对用户录入的真实持仓提出持有/退出复核，没有自动执行。各角色独立配置Messages或Chat协议，不按模型名猜路径，不付费修复坏JSON或因为观望换模型。

本机最终主分析选已验证的gpt-6.1-sol，deepseek-v4-pro复核、deepseek-flash持仓，原Claude连接留作可配置备用但本次上游失败。连接参数显式复制至期权私有配置，源文件不改。每轮主备各一次，只在传输/HTTP408/429/5xx失败接手；scope/引用/JSON/业务观望拒绝不接手。原始K线无损列数组、目录Pointer和提示Schema去除重复枚举只压缩输入，真实wire及本地完整验证保持。

## 时效与风险

数据/契约/新闻覆盖未知时可以保留研究事实，但不能产生可考虑买入通知。到期须覆盖预期兑现时间及缓冲；不提供卖方裸卖、不滚仓、不将主观置信度称胜率。未配置每笔最大权利金预算时只展示最小交易单位成本，不猜仓位。费用是用户可改的保守估计，不冒充账户真实费率。情景是定价敏感性估算，不是概率加权收益或可成交保证。

AI每次POST有持久预算预留，超时仍消耗；输入过期不请求，成功返回后复核最新指数/盘口/交易状态与原计划。发送前还检查快照期限、触发区间、失效和目标、最高权利金及原合约身份。只在通过复核、风险变化、失效或运行故障状态改变时发送通知；默认观望不刷屏。

SQLite记录扫描、完整事实/可见结构化回复、usage、通知预留/确认/未知、人工持仓和真实平仓。凭据不写数据库。跨进程文件锁、事务和唯一检查点防重复扫描；发送结果未知不自动重发。建议不是成交，只有显式人工录入才建立持仓。失效只撤销建议，不伪造平仓；人工成交和后续建议保留原始记录。

## 交付验证

离线合成快照必须标明演示、禁止真实通知；验证指标与时间、盘口/合约单位、情景算术、JSON与引用、双AI拒绝、时效更新、预算/重启去重、人工持仓隔离、飞书失败状态。公网诊断与小模型连接测试单独标记，不能将fixture通过称为公网联通或盈利验证。提交本地master，不推送，不启动交易或持续扫描进程。
