## 已知基线与取舍

架构与已知问题回忆参照 myq-xauusd 的 ETH/XAU 范围、confirmed-binance-option-v1 和 options-ai-json-v2 记录。原 make_pack 已把 K 线按 candle_columns 列化，prompt_schema 已移除提示文本中的大 r 枚举；不能把已做的优化重新当成新修复。结构化输出和本地仍有完整枚举。离线平直 MT5 ETH 样例的 canonical pack 为 74884 字符，其中 33505 字符是完整路径证据目录；波形演示样例目录占 57193/118058 字符。不能把字符当 token，亦不能用样例认定截图服务器已部署当前版本。

选用中立于模型供应商的无损输入编码，保持字段和全部分析事实。暂不增加付费请求、提示缓存专有参数、模型切换、降档、改扫描频率或人工预算；第三方路线未验证缓存语义，不能承诺缓存折扣。不得删除技术规则/原周期/K 线、放宽鲜活/JSON/证据门或借此恢复 BTC 独立机会。

## 编码与边界

`options_analysis/input_wire.py` 声明 `inline-evidence-v1`。将 canonical pack 的每个可引用标量在原路径替换为单键 `{r编号:原始值}`，例如 `ma60:{"r17":3000.25}`；未引用的字段、数组、空值、文字和原始 K 线原样保留，省去另一个重复长路径目录。scope 逐字保留；模型只输出该 r 编号，不能用输入包装格式替换回复字段。显式系统说明原值读取、引用、旧卡引用区别及事实不可信边界。

编码器先核对唯一连续编号、唯一存在路径和可见标量，天然单键 r 对象冲突拒绝；本地解码重新构建完整目录，与原 pack 的规范 JSON 逐字相等才可预留并发送。重复/容器/空标量引用、悬空目录、非法版本/字段不猜测修复。解码器只用于本地证明和离线夹具，不在模型回复接收路径使用。每个编号仍一一指向原始可见值，数值精度和类型保持。

`ai.py` 只替换传输输入和相应说明，保存 canonical pack/schema 与真实 wire_input。原完整严格 Schema、scope、方法状态及真实合约门在本地保持；structured 模式的线端原完整枚举保持。备用沿原网络/HTTP 分类接手同一事实，不增加坏 JSON 或正常拒绝的付费重审。未知/旧 scope、引用和候选仍拒绝。

每次请求保存 `input_transport`：canonical/wire 正文字符量、正文 UTF-8 字节、系统字符量、完整请求体 UTF-8 字节、证据数和正文/系统摘要。包含新编码说明的系统开销应计入离线比较；这些不是 token 估算或账单。请求返回后仍仅保存数值 usage，私有思考/凭据/HTTP 头不落盘。

## 本地用量核对

新增 `usage_report.py` 与 `usage --hours 1..168`，只读打开已存在的 SQLite，不创建、迁移或写状态，也不读完整 input_json。按标的、角色、模型、协议列实际请求/成功失败、原始 usage 各计数及本版本字符统计；旧库缺元数据列仍可读。缓存等计数字段保留原名，不能随意相加或映射第三方价格；缺 usage 不等于未计费，小联通请求若编码略增字符也如实显示负节省，不隐藏。
